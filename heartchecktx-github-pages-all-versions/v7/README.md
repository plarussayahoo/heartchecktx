# Heart Check TX — V7 Mock Merch Collection
Based on V6 with a six-product merch grid inspired by the uploaded Kublai Khan TX storefront's New Arrivals section.

Open `index.html` directly in a browser. Mockups are made with HTML/CSS and the user's original artwork; no third-party commerce code.

All product titles, prices, descriptions and garment visuals are **fictional placeholders**. Product buttons open working preview dialogs; there is **no cart or checkout**. Replace them with real product photographs, sizes, inventory, pricing and actual commerce integration before selling anything.

Tour, music, biography and contact details also remain placeholders.
